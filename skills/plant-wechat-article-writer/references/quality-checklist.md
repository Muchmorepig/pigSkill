# 完成前检查清单

## 内容与事实

- [ ] 标题与正文内容一致
- [ ] 时间范围准确
- [ ] 预印本提示与实际情况一致
- [ ] 英文标题、期刊、平台、日期、DOI 和链接准确
- [ ] 物种名、基因名、蛋白名和软件名未被错误改写
- [ ] 没有编造作者、图号、样本量、数据、性能或结论
- [ ] 相关性没有被写成因果关系
- [ ] 计算预测没有被写成功能验证
- [ ] 编辑观点与论文结论已经区分
- [ ] 用户自身方法只在确实相关时提及

## 结构

- [ ] 已选择合适的文章模式
- [ ] 前言交代了范围和本期特点
- [ ] 速览能够独立概括每项研究
- [ ] 研究顺序体现编辑取舍
- [ ] 二级标题具有明确问题或主题
- [ ] 不同研究没有机械套用完全相同的小节
- [ ] 重点研究得到更充分解释
- [ ] “为什么重要”说明了具体影响
- [ ] 推荐精读项给出了明确理由

## 语言与排版

- [ ] 段落长度适合公众号阅读
- [ ] Markdown 标题层级符合选定模式
- [ ] 加粗和斜体没有过度使用
- [ ] 引用块格式完整
- [ ] 中英文和数字间距基本统一
- [ ] 没有标题党或营销式表达
- [ ] 没有不必要的复杂表格
- [ ] 链接没有被截断

## 文件

- [ ] 文件名来自最终标题
- [ ] 非法文件名字符已移除或替换
- [ ] 正文没有重复公众号总标题
- [ ] 文件仅包含最终文章
- [ ] 文件使用 UTF-8 编码
- [ ] 目标 `.md` 文件确实存在且可读取

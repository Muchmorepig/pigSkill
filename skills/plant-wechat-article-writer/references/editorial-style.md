# 编辑语言与公众号排版规范

## 默认风格

- 专业但不生硬
- 有研究者视角和问题意识
- 有编辑取舍
- 适度解释方法
- 不逐句翻译摘要
- 不为了通俗而牺牲科学准确性

推荐句式：

- “真正缺少的是一个更加具体的答案：……”
- “这项研究补上了这一环节。”
- “值得注意的是……”
- “这意味着……”
- “从实验设计角度看……”
- “这项工作的另一个价值，在于……”
- “需要注意的是，这里仍然不能说明……”

避免营销式表达：

- 震撼
- 炸裂
- 不看后悔
- 史诗级突破
- 彻底改写教科书

除非证据充分，避免：

- 首次
- 首个
- 彻底解决
- 颠覆
- 革命性
- 世界领先
- 完全证明
- 无可争议

## 证据措辞

预印本使用：

- “作者报告”
- “研究提出”
- “结果显示”
- “可能”
- “提示”

严格区分：

- 表达相关与调控关系
- 共定位与直接互作
- 富集与细胞命运决定
- 计算预测与功能验证
- 侧面支持与直接证明

## 标题

中文章节标题优先使用问题句或概括句：

```markdown
## 原生质体化过程中，细胞如何变化？
## 生长素如何在几秒内打开一个钙通道？
## 从“几个元件”扩展到十个转录单元
```

避免直接使用：

```markdown
## Paper 1
## A spatiotemporal single-cell atlas reveals...
```

## Markdown 层级

为复现既有公众号文章视觉结构，扩展解读型默认采用：

```markdown
## 前言
# 速览
## 单项研究
### 研究内部小节
# 推荐优先精读研究
```

这是一种公众号视觉层级，不要求传统文档必须从一级标题开始。

精简模式可以使用：

```markdown
# 前言
## 📌 精选前沿
#### 单项研究
```

## 段落

- 每段通常 2–5 句
- 一个自然段表达一个主要意思
- 复杂结论拆成多个段落
- 段落之间保留一个空行
- 避免连续出现摘要式长段落

## 强调

加粗用于：

- 速览标题
- 关键数字
- 核心结论
- 重点提示

不要整段加粗。

斜体可少量用于：

- 需要突出的问题
- 英文学名
- 一组并列研究问题

## 引用块

引用块可用于：

- 预印本提示
- 机制链条
- 方法开发中的关键问题
- 本期总体观察

多行机制链条应保持每行 `>`：

```markdown
> 激素感知  
> → 受体定位变化  
> → 下游元件对接  
> → 动态细胞响应
```

## 列表和表格

列表适合实验建议、工具改进和证据类型，通常为 2–6 项，避免过深嵌套。

微信公众号对复杂 Markdown 表格兼容有限。除非用户明确要求，否则改写为短段落、编号列表或加粗字段。

## Emoji

扩展解读型默认少用 Emoji。

精简周报可在大栏目中少量使用：

- 📌 精选前沿
- 📖 方法相关推荐
- 🛠️ 工具
- 💡 本周小结与实验启发

不要在每项研究标题前添加 Emoji。

## 中英文和数值格式

中文与英文缩写、数字之间通常保留空格：

```text
植物 scRNA-seq 数据
约 159,000 个细胞
21 nt 和 24 nt 小 RNA
AFB1 与 CNGC14 形成复合体
```

统一范围、单位和特殊符号：

```text
2–8 周
约 6 小时
Ca²⁺
10 个转录单元
```

不随意修改基因、蛋白、软件、物种和数据库名称的大小写。

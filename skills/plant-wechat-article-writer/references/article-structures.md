# 文章结构参考

## 1. 扩展解读型

这是默认结构，适合素材充分、需要解释研究背景、机制和实验启发的植物研究周报。

```markdown
## 前言

说明周报由来、本期关注方向和覆盖日期。

周期：**YYYY年M月D日—M月D日**

> 仅在事实准确时说明“以下研究均为预印本，相关结论仍待同行评议”。

# 速览

**中文概括标题**。一句话概括关键方法和核心发现。

**中文概括标题**。一句话概括关键方法和核心发现。

## 面向核心问题的中文标题

**论文题目**：英文标题

**来源：**平台或期刊，日期

**DOI：**DOI

背景、未解决问题和研究设计。

### 根据研究内容设计的小标题

关键结果、意义或实验启发。

## 下一项研究的中文标题

……

# 推荐优先精读研究

#### 推荐研究的中文名称

说明推荐理由、适合读者和最值得关注的实验或分析。
```

可按素材增加：

```markdown
# 方法相关推荐
# 工具与资源
# 本周小结与实验启发
# 参考资料
```

没有实际内容时不要强行增加栏目。

## 2. 精简周报型

适合素材较少、用户明确要求简洁，或每项研究只有标题、链接和简短评价的情况。

```markdown
# 前言

时间范围和总体观察。

> 本期总体印象。

## 📌 精选前沿

#### 研究中文名称

发表信息：平台，日期

标题：英文标题

原文链接：链接

**为什么重要：** 具体说明研究价值。

**关注点：**

1. 最值得阅读的内容
2. 可借鉴的方法
3. 使用或解释时的注意事项

## 📖 方法相关推荐

……

## 🛠️ 工具

……

# 💡 本周小结与实验启发

总结本期共同趋势。
```

精简模式可少量使用 Emoji，但不要在每一项研究标题前使用。

## 3. 专题文章型

适合多项素材围绕同一个问题，例如“植物原生质体制备偏差”“空间组学如何解析复杂组织”或“植物小 RNA 分析工具”。

```markdown
## 前言

提出共同问题和文章范围。

# 核心问题

解释该问题为什么重要。

## 证据一：研究或方法

## 证据二：研究或方法

## 不同研究之间如何衔接？

综合比较证据、差异和局限。

# 对实验与分析的启发

给出有证据支持的实践启发。

# 总结
```

专题文章应重组素材，不按论文发布日期机械排列。

## 前言规则

前言通常为 1–3 段，完成三件事：

1. 交代文章或周报的由来
2. 写清覆盖时间
3. 提醒本期共同特点或证据状态

避免：

- 随着科技不断发展
- 在当今时代背景下
- 众所周知
- 植物研究一直是热门领域

## 速览规则

每项速览使用：

```markdown
**中文概括标题**。一句话说明使用了什么方法、发现了什么或解决了什么问题。
```

速览不是英文题目、DOI 和实验细节的堆积。

建议顺序：

1. 与本期主线最相关
2. 对实验设计影响最大
3. 新方法或新工具
4. 重要机制研究
5. 补充性资源

## 推荐优先精读研究

多项研究文章默认选择一项优先推荐。选择依据：

- 会改变常见实验或分析习惯
- 方法框架可广泛复用
- 与植物实验设计直接相关
- 证据链完整
- 与用户当前方向具有明显启发

必须解释推荐理由，不能只写“推荐阅读”。

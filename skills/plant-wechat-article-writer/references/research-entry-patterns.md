# 不同研究类型的叙事模式

这些问题用于帮助组织自然叙事，不应机械转化为每篇论文完全相同的固定栏目。

## 单细胞、空间组学或细胞图谱研究

优先回答：

- 为什么该组织、时期或过程难以解析？
- 样本如何分期，选择了哪些组织或处理？
- scRNA-seq、snRNA-seq、空间组学、代谢组或遗传数据如何组合？
- 不同细胞类型或空间区域如何分工？
- 图谱是否回答了生物学问题，而不只是增加聚类数量？
- 哪个实验或分析框架值得借鉴？

可用小标题：

```markdown
### 研究发现了什么？
### 不同组织层如何分工？
### 单细胞与空间信息如何形成证据链？
```

## 样本处理、实验方法或基准测试研究

优先回答：

- 现有流程的核心问题是什么？
- 作者比较了哪些条件？
- 是否存在关键时间窗口或混杂因素？
- 偏差会影响哪些下游分析？
- 实验设计应该如何调整？
- 对用户使用或开发的方法有什么启发？

可用小标题：

```markdown
### 六小时，是一个值得注意的时间窗口
### 为什么重要？
### 实验设计应该如何调整？
```

“为什么重要”应具体落到细胞类型注释、差异表达、轨迹推断、数据整合、批次设计或状态解释。

## 生物信息学软件或数据库

优先回答：

- 现有工具为什么容易误判或使用困难？
- 新工具改变的是算法、解释层还是工程流程？
- 基准测试使用了哪些参照？
- 召回率、特异性、假阳性或可解释性如何变化？
- 适合放在现有流程的哪个位置？
- 使用限制是什么？

可用小标题：

```markdown
### 这个工具解决了什么问题？
### 基准测试表现如何？
### 对现有分析流程的启发
```

不得仅凭作者报告就写成“全面优于所有工具”。

## 分子机制研究

优先回答：

- 过去缺失的机制环节是什么？
- 候选蛋白、受体、通道或转录因子如何连接？
- 事件发生在什么亚细胞位置和时间尺度？
- 作者使用了哪些互补证据？
- 研究改变了什么传统认识？
- 是否形成遗传学、成像、生化和表型的证据闭环？

可用小标题：

```markdown
### 受体与下游元件如何对接？
### 它改变了什么认识？
### 一项机制研究如何形成证据闭环？
```

## 植物合成生物学或工程工具

优先回答：

- 原体系在哪些环节失败？
- 新设计具体修改了什么？
- 容量、成本、成功率或转化兼容性是否改善？
- 改进能否被其他实验室复用？
- 工具价值是否超出“新增一套质粒”？

可用小标题：

```markdown
### 从几个元件扩展到更大体系
### 如何降低大型构建成本？
### 为什么它不仅是一套新质粒？
```

## 植物发育与遗传研究

优先回答：

- 研究聚焦哪个发育阶段、组织或细胞命运？
- 候选因子来自表达、遗传、成像还是多组学证据？
- 表型与分子读出是否处于同一因果链？
- 是否区分必要性、充分性和相关性？
- 研究如何连接细胞行为与器官表型？

## 资源型论文

数据库、图谱或材料资源应说明：

- 资源包含什么
- 数据质量和覆盖范围
- 查询或下载方式
- 最适合解决哪些问题
- 关键限制
- 与已有资源的互补关系

## 用户课题关联

只有在素材支持时才加入用户自身方法或课题的关联。

推荐表达：

- “为该设计逻辑提供侧面支持”
- “提示应进一步评估……”
- “与这一方法试图解决的问题一致”
- “可作为后续实验设计的参考”

避免：

- “证明该方法是最好的”
- “直接验证了用户方法”
- “说明其他方法均不可靠”
